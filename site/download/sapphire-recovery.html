Sapphire Pulse recovery

For a device in locked mode when Sapphire can’t be reached. Works with no internet.

This copy of the app isn’t working out codes correctly. Don’t use it: use the copy in 1Password.

1. On the device

On the lock screen, press “Can’t reach Sapphire?”. A box shows the Recovery ID and a 6-digit Number. Keep it open. (It also shows an Admin no., needed only on the Passwords tab.)

2. Master key

From 1Password. It stays on this page only: it isn’t saved or sent anywhere, and it’s cleared after 5 minutes.

3. The Number

Type the 6-digit Number from the same box to get an 8-digit unlock code. Type it on the lock screen: it opens the desktop for an hour, once.

Unlock code: type this on the lock screen and press Unlock

3. Passwords

Only if the lock screen itself won’t start (then use the Recovery ID from the device’s page in Sapphire, or the serial number on the device). At the Windows sign-in, choose Other user, or press Ctrl+Alt+Del and Switch user, and sign in as SapphireAdmin.

Other numbers
SapphireAdmin
Sapphire (everyday account)
BitLocker recovery password

If the admin password doesn’t work, try the Admin no. one higher: the device may have just changed it.
